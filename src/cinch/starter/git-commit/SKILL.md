# Git Commit Guidelines

1. Format: `<type>(<scope>): <summary>` (e.g. `feat(api): add preview endpoint`).
2. Types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`.
3. Imperative mood in summary ("add feature" not "added feature").
4. Keep first line under 72 characters.
5. In body: explain the *why* and *what*, not just the *how*.
