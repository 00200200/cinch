# Humanizer Writing Guidelines

When editing or drafting technical documentation, pull requests, and commit messages:

1. **Eliminate filler openers:** Never start responses with "Sure!", "Certainly!", "Here is a breakdown", or "In this guide, we will...".
2. **Prefer active voice:** Write "Run the server" instead of "The server can be run by executing".
3. **Cut empty intensifiers:** Remove words like "very", "super", "simply", "just", "crucial", "essential".
4. **Lead with the takeaway:** Put the command or decision in the first sentence.
